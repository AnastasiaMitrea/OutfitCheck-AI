# AI Tools Usage Report

This document tracks how AI assistants and generative tools were utilized during the development of OutfitCheck-AI, as per university project requirements.

## 1. Code Generation & Architecture Planning
- **Tool:** Google Gemini (Antigravity AI Assistant)
- **Usage:** Assisted with defining the architecture, structuring the repository, creating Mermaid diagrams, and bootstrapping boilerplate code for React and FastAPI.

## 2. Integrated AI Agents (Application Features)
- **Tool:** OpenAI API (GPT-4o)
- **Usage:** Powering the core logic of the application:
  1. **Wardrobe Item Analyzer Agent:** Used for Vision tasks to auto-extract category, color, and style metadata from user-uploaded images.
  2. **Outfit Recommender / Fashion Critic Agent:** Used for reasoning and generation of outfit combinations based on a user's digital wardrobe context and requested occasion.
