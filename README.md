# AI Virtual Wardrobe

An AI-powered Virtual Wardrobe application that allows users to manage their clothes, generate outfits, and receive fashion advice using local AI models.

## User Stories

1. **As a user**, I want to upload photos of my clothes so that I can add them to my virtual closet.
2. **As a user**, I want my uploaded clothes to be automatically categorized (e.g., shirt, pants, dress) and color-tagged by an AI agent so that I don't have to enter this data manually.
3. **As a user**, I want to view all my clothes in a gallery format so that I can easily browse my wardrobe.
4. **As a user**, I want to delete clothing items from my virtual closet if I no longer own them.
5. **As a user**, I want to mix and match clothes on a visualization canvas so that I can preview outfits.
6. **As a user**, I want to receive feedback on my outfit's color matching and style from an AI Fashion Critic so that I can improve my look.
7. **As a user**, I want to save my favorite outfits so that I can easily find them later.
8. **As a user**, I want to search my wardrobe using natural language (e.g., "black elegant dress") so that I can quickly find specific items.
9. **As a developer**, I want the AI models to run locally using Transformers.js so that user privacy is maintained and no cloud API costs are incurred.
10. **As a developer**, I want the application to have automated tests and a CI/CD pipeline so that code quality is ensured.
